Get it running.

One file, no installer. Save it to a USB stick or another drive, not the drive you lost files on, and run it from there.

Download Lifeline Other systems

Pick your system below.

Windows

Windows 10 and 11 · 64-bit

Lifeline-Windows.exe
  1. Save the file to a USB stick or a different drive.
  2. Double-click it. When Windows asks "Do you want to allow this app to make changes?", choose Yes. Lifeline needs this to read drives directly, and it only ever reads.
  3. If you see "Windows protected your PC", click More info → Run anyway. This appears because the app isn't code-signed yet.

Command line, from a terminal: Lifeline-Windows.exe scan D: --out E:\Recovered

Linux

x86-64 · glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 and newer)

Lifeline-Linux-x86_64
  1. Save the file to a USB stick or a different drive.
  2. Make it runnable: right-click → Properties → Allow executing as program, or run chmod +x Lifeline-Linux-x86_64.
  3. Double-click it and press Restart with administrator rights when asked, or start it with administrator rights yourself:
    sudo -E ./Lifeline-Linux-x86_64

macOS

Apple silicon (M1 and newer) · macOS 13+

Lifeline-macOS-arm64.zip
  1. Unzip it and move Lifeline.app anywhere except the drive you lost files on.
  2. The first time, right-click → Open, then Open again. macOS asks because the app isn't notarized yet.
  3. Allow Full Disk Access in System Settings → Privacy & Security, and enter your password when Lifeline asks for administrator rights.

Intel Mac? Use pip install lifeline-recovery below.

Any system, with Python

Python 3.10+ · Windows, macOS (Intel too), Linux

pip install lifeline-recovery
  1. Then run lifeline to open the app, or lifeline --help for the command line.
  2. Start it with administrator rights (an admin terminal on Windows, sudo -E lifeline on Linux/macOS), or let the app restart itself with them.

Check your download

Every release lists a SHA-256 checksum for each file in SHA256SUMS.txt. Compare it with what your system reports:

Windows: certutil -hashfile Lifeline-Windows.exe SHA256
Linux: sha256sum Lifeline-Linux-x86_64
macOS: shasum -a 256 Lifeline-macOS-arm64.zip

Every build is made in the open

The binaries are built by GitHub Actions from the public source on real Windows, Linux and macOS machines, after the test suite passes. You can read the build recipe, see all releases, or build it yourself with build_exe.bat / ./build.sh.
